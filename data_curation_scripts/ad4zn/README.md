`zinc_pseudo.py` and `AD4Zn.dat` are copied unmodified from
[AutoDock-Vina](https://github.com/ccsb-scripps/AutoDock-Vina) (Apache-2.0),
`example/autodock_scripts/` and `data/`.

They implement the AutoDock4Zn force field (Santos-Martins et al., J. Chem. Inf.
Model. 2014, 54, 2371), used by `build_zinc_maps.py` because Vina's default
scoring has no zinc-coordination term.
